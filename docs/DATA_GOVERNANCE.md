# Data governance

## Source classes

| Class | Example | Allowed use |
| --- | --- | --- |
| Organizer feed | Timing export or contracted webhook | Operational storytelling under written agreement |
| Official public context | Race course, rules, and archive pages | Attributed contextual retrieval subject to source terms |
| Athlete-consented data | Optional profile, quote, or media | Only for the consented purpose and retention window |
| Synthetic fixture | Checked-in Western States-inspired simulation | Public portfolio demonstration and automated tests |

The repository does not scrape UTMB, Western States, athlete accounts, or commercial result providers. Public visibility is not the same as a license to bulk ingest or commercialize. Each connector must carry source owner, permitted purpose, retention, refresh cadence, and takedown contact before activation.

## Sensitive inference policy

Timing changes must not be converted into claims about injury, dehydration, distress, intent, motivation, emotion, or medical condition without an authorized primary source and human review. The safety editor enforces a first deterministic gate; editorial policy remains authoritative.

## Retention

- Raw timing: organizer contract and operational need
- Generated drafts: short newsroom retention unless approved
- Approval records: append-only audit retention
- Trace records: metadata only; no raw athlete narrative
- Training data: only human-approved, rights-cleared examples with documented provenance

## Public sources used by the demo

- Western States official home/course description: https://www.wser.org/
- Western States official participant guide: https://www.wser.org/participant-guide/
- Western States official year-by-year archive: https://www.wser.org/year-by-year/

These links support course and historical context only. All demo timing and athlete identities are synthetic.
